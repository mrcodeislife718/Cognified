# Cognified — Portfolio Proof Contract

**Track:** Commercial immersive learning platform

Cognified is complete only when skill compilation, learner sessions, adaptive instruction, evidence capture, and mastery updates produce measurable learning transfer rather than merely engaging experiences.

Required proof: end-to-end skill-package/session/mastery flows; correctness and replay tests; failure tests for bad source material, interrupted sessions, corrupted events, device/runtime loss, and adaptation errors; benchmarks for learning gain, delayed retention, transfer to changed contexts, completion, latency, and runtime cost; privacy/security; deployment; real learners; paid adoption/retention where commercialized.

**Next proof target:** preregister a small skill curriculum, compare pre/post/delayed-transfer performance against a baseline learning method, and preserve learning events plus mastery predictions for calibration analysis.
