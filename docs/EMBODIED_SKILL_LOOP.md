# Cognified Embodied Skill Acquisition

Cognified's target is not course completion. It is verified transition from information to reliable, increasingly automatic execution.

```text
source knowledge
  -> skill graph
  -> explanation and demonstration
  -> guided physical practice
  -> sensor observation
  -> motor error measurement
  -> corrective repetition
  -> context variation
  -> unassisted execution
  -> delayed retest
  -> verified automaticity
```

## Production claim boundary

Cognified does not claim to directly write arbitrary knowledge into neurons. The production system instead engineers practice conditions that drive normal learning and neuroplastic adaptation, then measures resulting behavior. Neural or physiological sensing can be added as evidence, but behavioral competency remains the primary truth until stronger causal validation exists.

## Embodied evidence

The motor-learning layer can ingest motion samples from XR controllers, vision pose estimation, wearables, haptics, instrumented tools, robotics interfaces, or future validated neural/physiological sensors. Evidence dimensions include timing, path consistency, force consistency, action order, successful completion, assistance dependency, error recovery, transfer to new contexts, retention, and repetition-to-automaticity.

## Automaticity

`MotorLearningEngine` calculates a bounded automaticity signal from repeated execution consistency, correct sequencing, and independence. This is a training metric, not a direct measurement of a specific neuron's firing. Future versions should add task-specific norms, movement embeddings, expert-reference trajectories, reaction-time decomposition, fatigue detection, transfer testing, delayed retention, and confidence intervals.

## Closed loop

Every attempt should produce evidence that changes the next training experience. The long-term runtime should select not only what concept comes next, but what physical variation, speed, resistance, environment, sensory cue, or assistance level best reduces the learner's current error profile while avoiding overtraining and unsafe execution.
